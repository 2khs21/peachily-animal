# Peachily

달에 남겨진 동물들을 로켓에 태워 지구로 데려가는 어린이용 덧셈 미니게임입니다.  
숫자 키패드로 연료를 채워 **10의 보수**(두 수의 합이 10)를 맞추면 로켓이 발사됩니다.

로컬에서 `index.html`을 열거나, 아무 정적 서버로 폴더를 서빙하면 바로 실행할 수 있습니다.

```bash
npx serve .
```

---

## 플레이 흐름

1. **태우기**를 눌러 달에 있는 동물을 로켓에 태웁니다.
2. 수식의 빈칸에 숫자(1–9)를 입력해 연료 칸을 하나씩 채웁니다.
3. 10칸이 차는 순간 게이지와 수식 칸이 빛납니다. 10을 넘기면 한 박 머문 뒤 11칸부터 붉은색으로 채워집니다.
4. 합이 10이면 **확정**(또는 Enter)으로 발사합니다.
5. 로켓이 지구에 도착한 뒤 **다시 준비**로 다음 동물을 구출합니다.
6. 동물 10마리를 모두 구출하면 클리어됩니다.

## 디렉토리 구조

```
peachily/
├── README.md                  # 프로젝트 소개와 파일 역할
├── index.html                 # 게임 페이지 진입점 (마크업)
├── .gitignore                 # Git에서 제외할 파일 규칙
├── css/
│   ├── style.css              # 장면·로켓·동물·버튼 등 전체 레이아웃
│   └── tens-complement.css    # 연료 게이지·덧셈 수식 위젯 스타일
├── js/
│   ├── main.js                # 엔트리. 게임을 시작함
│   ├── game.js                # 탑승·발사·지구 이동·리셋 흐름
│   ├── animals.js             # 동물 데이터, 배치, 탑승 애니메이션
│   ├── problems.js            # 10문제의 시작 숫자(a) 목록
│   ├── tensComplement.js      # 연료 입력·게이지 채우기·확정
│   └── smoke.js               # 로켓 연기 파티클
└── public/assets/
    ├── animals/               # 동물 스프라이트 (webp 사용, png는 원본)
    ├── background/            # 우주·달 표면 배경
    ├── earth/                 # 지구 이미지
    └── rocket/                # 로켓 이미지
```

## 파일별 역할

### 루트

| 파일 | 역할 |
| --- | --- |
| `README.md` | 프로젝트 소개, 실행 방법, 플레이 흐름, 파일 역할을 적습니다. |
| `index.html` | 게임 화면의 HTML. 상태 문구, 연료 위젯, 로켓, 발사대, 동물 영역, 조작 버튼을 두고 `js/main.js`를 모듈로 불러옵니다. |
| `.gitignore` | OS·에디터·환경변수·빌드 산출물 등 Git에 올리지 않을 파일을 지정합니다. |

### `css/`

| 파일 | 역할 |
| --- | --- |
| `style.css` | 우주 배경, 지구, 로켓, 발사대, 달 표면, 동물, 연기, 조작 버튼의 위치·크기·애니메이션을 담당합니다. |
| `tens-complement.css` | 10칸 연료 게이지와 `8 + □ = 8` 형태의 수식 패널 스타일을 담당합니다. 부족/정확/초과에 따라 색이 바뀌고, 10칸이 차는 순간 글로우가 퍼지며, 초과 칸은 붉은색입니다. |

### `js/`

| 파일 | 역할 |
| --- | --- |
| `main.js` | 앱 진입점. `initGame()`만 호출합니다. |
| `game.js` | 게임 상태 머신. 동물 탑승, 연료 확정 후 발사, 지구로 가는 궤도 애니메이션, 구출 기록, 다시 준비(리셋)를 묶습니다. |
| `animals.js` | 동물 10마리의 이름·조사·위치와 탑승 순서를 정의합니다. 달에 남은 동물을 그리고, 로켓 창문으로 이동·탑승시킵니다. |
| `problems.js` | 1번부터 10번까지 시작 연료량 `a`를 둡니다. 정답은 항상 `10 - a`입니다. |
| `tensComplement.js` | 숫자 키 입력으로 연료 칸을 하나씩 채우고, 10이 되는 순간 게이지와 수식을 빛냅니다. 10을 넘기면 잠깐 머문 뒤 초과 칸을 붉은색으로 채웁니다. 합이 10일 때만 확정 콜백을 호출하고, 발사 중에는 입력을 잠급니다. |
| `smoke.js` | 점화·비행 중에 로켓 노즐 쪽에 연기(`<i class="smoke">`)를 만들어 붙입니다. |

### `public/assets/`

| 경로 | 역할 |
| --- | --- |
| `animals/*.webp` | 실제 화면에 쓰는 동물 이미지. `animals.js`가 `id.webp`로 불러옵니다. (`cat`, `dog`, `fox`, `rabbit`, `pig`, `bear`, `monkey`, `sheep`, `raccoon`, `tiger`) |
| `animals/*.png` | 같은 동물의 PNG 원본. 런타임에서는 사용하지 않습니다. |
| `background/space.webp` | 우주 배경. `style.css`의 `.game` 배경입니다. |
| `background/moon-surface.webp` | 달 표면. `style.css`의 `.ground` 배경입니다. |
| `background/` 나머지 | `space.png`, `moon-surface.png`, `moon-surface-2.webp`, `space-moon-bg.webp` 등 미사용 후보 에셋입니다. |
| `earth/earth.webp` | 화면 오른쪽 위 지구. 로켓이 도착하는 목표입니다. |
| `rocket/roket.png` | 화면에 쓰는 로켓 이미지. |
| `rocket/` 나머지 | 투명 배경 로켓 원본(`.png`, `.avif`). 런타임에서는 사용하지 않습니다. |

